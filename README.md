# Shortcut-Lib
An Apple shortcut "library" which can install shortcuts DIRECTLY from the library shortcut

# How does it work?
The shortcut Library uses github, so updates dont occur when new shortcuts are added (yay!)

It uses base64 encoded files to download the shortcut, and it also does so to display the icon.

# How can I post/submit my own shortcut?
You can post/submit your own shortcut using discussions in the "Submissions" category, I will try and keep up! 

**SUMBISSIONS SHOULD INCLUDE: ICLOUD LINK TO SHORTCUT (BASE 64 looks UGLY so send an icloud link!) (I go through the shortcuts so people dont post anything bad)**
